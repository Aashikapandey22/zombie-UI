# 🧟 Zombie API Detector

### Detect the Forgotten. Secure the Connected.

Zombie API Detector is a hackathon project focused on the problem of forgotten, undocumented, and potentially vulnerable APIs. It combines a modern web interface with an immersive visual experience to highlight the importance of API security.

## ✨ Features

- 🌍 **3D Earth Experience** — An immersive globe visualization representing the connected digital ecosystem.
- 🕸️ **Network Visualization** — Animated network connections illustrating interconnected systems.
- 💥 **Cinematic Animations** — Dynamic visual effects and smooth transitions.
- 🎨 **Modern UI** — An interactive interface with polished visual styling.
- 🔐 **API Security Awareness** — Highlights the risks associated with unmanaged and forgotten APIs.

## 🔍 What Are Zombie APIs?

Zombie APIs are endpoints that remain accessible even after they are no longer needed, maintained, or properly documented.

They can increase an organization's attack surface and introduce security risks, including:

- Outdated security controls
- Forgotten authentication requirements
- Unmonitored endpoints
- Potential exposure of sensitive data
- Difficulty maintaining an accurate API inventory

Identifying and managing these endpoints is an important part of API security.

## 🎯 Project Objective

The objective of Zombie API Detector is to make API security more engaging and accessible through an interactive web experience.

The project emphasizes the importance of discovering, monitoring, and managing APIs throughout their lifecycle.
